OPS 使用說明
📋 OPS 是宇德正式雲端多人同步系統，資料即時同步到 Firebase，所有已開通帳號共用同一份正式資料。
1. 帳號權限
依員工主檔的系統權限角色開通，只看得到自己權限範圍內的模組與資料；權限有問題請找李鎮宇或鄭詩褣調整。
2. 遇到問題怎麼回報
到左側「問題回報」新增一筆，記錄：所在頁面、操作步驟、預期結果、實際結果，方便查證。
3. 資料備份
完整管理者可隨時用左下角「下載資料備份」保留一份 JSON 快照；「上傳本機快照」會整包覆蓋雲端正式資料，非必要不要按。
4. 多人同時使用
不同筆資料會自動合併；同一筆資料被兩人同時修改時，畫面會提示衝突，請重新整理後再確認一次。
